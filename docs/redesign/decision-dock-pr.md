# 统一底部决策区与对话级信任

第一增量，基于已合并的 master `656ee54`。本 PR 不包含右侧产物分屏或浏览器自动化，也不合并 master。

## 改动

- Agent 一次提出 1–6 个问题，支持单选、多选、自定义文本、可选跳过、返回修改与一次提交。
- 问题、具体工具／成果批准、授权范围、文件恢复／整轮撤销及未知执行结果确认统一占据固定底部输入区；不需要另发“同意”或回答消息。
- 回答草稿与普通聊天草稿分开持久化；保留队列，立即发送补充要求明确作废旧决定。
- 支持逐次确认或明确授权本次对话；“开启可信对话”入口可以同时启用本机工具和对话级信任，后续轮次继承，全局关闭撤销。
- 旧提问 checkpoint 兼容迁移；提交绑定原 call ID／digest／revision，重复提交幂等，拒绝理由放回成对工具结果。
- 实测修正 DeepSeek 工具 schema：根 union 被 HTTP 400 拒绝，改为对象型并由 runtime 校验两种格式互斥。

## 验证

- 本地 103 项单元测试、11 个界面场景、类型检查、lint、生产构建、42 对设计 token 对比、Electron 隔离 smoke、完整 npm audit 均通过。
- 真实 Electron＋DeepSeek：多题／自定义／跳过、草稿跨重启、一次提交、取消、底部范围批准两份成果、实际 Node／Shell 及全局撤销通过。
- 原有真实桌面主回归：读取随机标记、审批重启、保存成果、拒绝及停止／重启不重放通过。
- DeepSeek、工具、IPC、SQLite 无替身，仅原生目录选择器使用虚构测试目录。Linux harness；真实 Windows/macOS 模型／安装／密钥存储未验收。

## 边界

默认文件自动快照保留，不重新引入逐文件审批。本机执行是系统用户权限，不是目录／OS 沙箱；快照不覆盖 Shell／JavaScript 或远端效果。未实现的分屏／网页操作留到下一增量。全局设置及 Skill 卸载保留原设置交互，本次统一的是会话中的决策。
