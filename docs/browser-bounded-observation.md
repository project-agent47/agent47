# 网页有界等待与定向读取

B1 沿用同一原生 WebContentsView、DeepSeek ToolLoopAgent＋TaskRuntime 和已有 Tab／对话／站点授权，不新增浏览器接管、任意脚本接口、扩展或登录权限。

## 内置工具契约

- `browserWait`：`tabId`、条件及 `timeoutMs`（250–15000，默认5000）。条件为 loaded、当前可提取文本包含指定片段、可见控件的精确名称、同站精确 URL。固定250ms采样，不点击、不重新提交、不自动刷新；超时返回 `timed_out` 而非冒称业务失败。已匹配只证明该观察，不证明远端业务成功。
- `browserRead`：保留原 tabId 调用；返回正文、控件引用与最多40个语义区域引用（main/article/section/region）。指定 `regionRef` 时同时传最新 `snapshotId`，沿用2分钟有效期、对话及页面绑定，不接收任意 CSS／JS。
- 分页：offset／limit 为规范化正文的 UTF-16 字符位置，limit500–8000，默认4000。返回 contentDigest、nextOffset、hasMore、capturedCharacters、captureTruncated、scope、observedAt。offset>0 必须带 expectedDigest；同一范围正文版本变化拒绝拼接，重新从0读取。

每次读取最多捕获64000字符，最多检查50000文本节点。分页终点只表示已捕获范围读完，不能代表整个网页。表单、输入值、脚本、隐藏内容、frame、shadow DOM 及未加载内容均不在正文覆盖内；元素观察也不读取密码或输入值。可见正文仍可能含用户隐私，原授权仍是内容进入模型的前提。

## 生命周期与权限

等待只观察当前可见、已授权的目标 Tab，切走、隐藏、关闭、撤权、授权版本变化、跨站都会终止；同站 URL 等待允许页面在同一授权内导航。取消中止本机轮询及未完成脚本结果交付；无法杀掉已经在 Chromium 执行的只读固定脚本。暂停沿用工具安全边界，因此最多等本次15秒有界等待结束。

等待不重建控件引用、不延长引用有效期，动作前应重新读取。全文/区域读后返回新的引用，旧引用不再可用。读取对主文档导航世代做前后检查，即使离开后返回相同 URL，也不能交付旧页面结果。DOM 读取不是事务快照，内容与控件间仍可能动态变化；控件操作保留已有可见性／描述绑定检查。

新读取开始时即作废上一组主进程引用，避免异步页面程序更新注册表后发生取消／异常，却仍能批准旧引用。失败后必须重新成功观察再操作，不增加新的审批轮次。

等待脚本只允许固定提取或控件名称观察；严格序列化条件，不执行模型字符串。超时不自动重放远端动作；已派发 click/fill 仍只返回 dispatched，未知效果仍走原核对区。

## 验收范围

单元覆盖输入边界、版本分页、区域失效、延迟加载、超时、取消、撤权、切换 Tab 与相同 URL 导航。原生 fixture 使用真实 WebContentsView／IPC／SQLite／DOM，但显式注入工具意图和 HTTPS 响应；真模型脚本由 DeepSeek 选择工具，只有受控测试网页响应为 fixture，随机标记验证实际读取。

真实验收限定 Linux harness；Windows/macOS 原生 CI 不等同真模型实机或签名安装。没有网站兼容率、业务成功率或速度排名；现有公共 HTTPS、临时会话、禁用密码／上传／跨 frame／视觉操作边界不变。
